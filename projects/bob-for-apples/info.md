For this project for my Electronics & Controls I class, we were tasked with building a simple game that uses a DC motor and at least one transistor and requires user interaction. I built a simple "bob for apples" game where one player uses a magnetic fishing rod to retrieve apples from a spinning barrel while the other user controls the spinning barrel using a button.
