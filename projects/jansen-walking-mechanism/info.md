For my Mechanics II class, we built a simple mechanism using LEGO bricks and used tracking software to conduct a motion analysis by tracing the path of motion from frame to frame and graphing this path using MATLAB. We repeated the motion analysis using SolidWorks and compared the path traces and velocities for both motion analysis methods.
